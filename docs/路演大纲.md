### P3 企业痛点与定位（1 分钟）

- **画面**：三个痛点 → 一个定位（Gartner CTEM 环节图，高亮「验证」）
- **口播要点**：
  1. 渗透测试/攻防演练**人力贵、周期长**：一个系统人工渗透 2~4 小时，全量资产根本测不过来；
  2. **暴露面变化快**：业务周周上线，人巡检跟不上，漏洞 window 期以月计；
  3. 直接拿 LLM 跑安全任务有**硬伤**：上下文爆炸、提交失控、难题占死资源（后面用实测数据展开）。
- **落点**：企业 CTEM 闭环「可见性 → 优先级 → **验证** → 处置」，缺的正是无人值守的自动化攻击验证——这就是 bsrc-agent 的位置。

### P4 核心理念（1 分钟）

- **画面**：一句话 + 三层分工示意
  > **成熟引擎干擅长的事，自研调度管全局经济，纪律层保每一分质量。**
- **口播要点**：
  - 关键判断：Claude Code 的「计划-执行-反思」循环在**单题攻坚**上已是最强，盲目自研解题循环是重复造轮子；
  - 但它有**长任务调度盲区**：并发槽位、止损、提交质量、token 失控——这正是工程价值所在；
  - 所以架构上「Claude Code 解题 + 自研编排」**各取所长**，我们的创新全部沉淀在框架层。

### P5 整体架构图（1.5 分钟）

- **口播要点**（沿一条题目的旅程讲，不要逐层念）：63 题队列 → 调度器 3 槽位取题 → 每题主控进程派发并行子代理 → 三通道提交闭环 → 复盘轮转 → 最后 45 分钟只打快赢题。

### P6 创新点 ①②（1.5 分钟）

**和别人不一样在哪——逐条给「实测证据」**

- **① Task 子代理分治 + 共享台账**（解多阶段题上下文爆炸）
  - 痛点：多阶段渗透题单会话最长烧到 **920 万 token** 仍解不出；
  - 解法：4~8 个子代理按方向分治（入口/横向/提权/CVE/云逃逸），独立上下文 + RELAY/HOSTS 共享文件——**上下文隔离了，情报不隔离**；
  - 证据：早期独立多进程架构 24 个 claude 吃爆 8 核沙箱，改子代理后**资源降一个量级**，4-flag 大题首轮拿全。
- **② 纪律层：把「提交质量」当代码问题治理，而不是 prompt 问题**
  - CLAIM/EVIDENCE 证据闸门：提交必须声明原始证据，推断/猜测禁止提交（对标榜首梯队 69 flag 仅 4 错提）；
  - 全通道错提熔断：一轮 **145 次错提**全部绕过脚本闸门——把熔断下沉到提交器统一闸门，单题 75 连错这类事故被硬性拦停。

### P7 创新点 ③④（1 分钟）

- **③ 全局预算经济学**：分级预算（有断点满额 / 无断点 12 分钟快验）+ 零进展退出 + endgame 收尾——**像基金经理管理 6 小时预算**。证据：同题三轮满预算零进展曾烧掉 **213 分钟**，治理后槽位永不空转。
- **④ 指挥体系与 hint 经济学**：advisor（强模型读全部进度产出定向 brief）+ critic（对抗审查）；官方 hint 扣 10% 但解不出的题扣 0——hard/多 flag 题**首轮就买方向**，落盘终身复用。

## 4. 答辩 Q&A 预备库（现场答辩维度）

**Q1：为什么用 Claude Code 而不是自研 agent 循环？**
> 单题攻坚它的计划-执行-反思循环已是最优，自研是重复造轮子；我们的工程价值在框架层——调度、止损、提交质量，这些它不做、竞品也没做好。实测 85.45 也验证了这个分工。

**Q2：企业内网怎么落地？会不会有破坏性？**
> 靶场里是全攻击链；企业模式计划只开「只读侦察 + 漏洞验证」：不改数据、不落勒索类动作，产出可复现 PoC 和报告。平台适配层预留好了，换环境只改一个文件。

**Q3：LLM 幻觉乱提交 flag 怎么治？**
> 三道闸：格式合理性预检、CLAIM/EVIDENCE 证据声明（无原始证据拒绝）、全通道错提熔断（≥10 次关停自动通道）。治理前后对比：一轮 145 错提 → 目标 <30。

**Q4：模型成本多少？**
> 双模型分层控制成本：flash 快扫 23.6%、pro 攻坚 76.4%，一轮 6 小时约 6.5 亿 token——相对同等产出的人力工时（3~4 周）低一个量级。

**Q5：和排行榜上其他 agent 的差异？**
> 不点评他人，讲自己三个差异化：子代理分治共享台账、代码级提交纪律层、全局预算经济学——这三个都是实测踩坑驱动的，每条都有前后对比数据。

**Q6：怎么保证没有作弊/内置答案？**
> 镜像零题目先验：无解法库、无历史 flag、无题目专属逻辑；平台侧会话与流量审计可验证；官方 hint 按计费规则购买。这也是我们主动删除早期解法库、用干净镜像重跑出 19655 的原因。

**Q7：题目更新/换靶场怎么办？**
> 能力在框架不在题库：playbook 按维度通用（已预埋 AI 应用/区块链新维度），平台协议走适配层。换靶场不改上层一行代码。

**Q8：如果时间无限，还能提多少分？**
> 6 小时里失分主要在多阶段渗透（60.71）——这类题需要长链横向移动；endgame 和预算策略已把时间利用率打满，下一步是多阶段专项的子代理编排优化。

**答辩技巧**：先结论后展开、每答 ≤45 秒；被问住就「这个问题我们实测数据是 X，机制上我理解是 Y，赛后可以验证」——诚实 + 给验证路径，比硬编强。
