# bsrc-agent 作品简介

## 一句话

**以 Claude Code 为解题大脑、自研调度与纪律层为骨架的全自动智能渗透 Agent**——Tsecbench v1 官方托管模式 6 小时无人值守拿下 **19655/23000 分（85.45%）、64 枚 flag、56/63 题全对**，全程零人工干预、镜像零题目先验（可审计干净跑分）。

## 作品思路

通用 LLM 循环解题的三大瓶颈：**多阶段题上下文爆炸**（单会话 920 万 token 仍解不出）、**难题占死并发槽位**（收卷前还在第三轮硬啃零进展题）、**提交质量失控**（一轮 145 次错提烧请求）。本作品的解法是三层分工：

1. **成熟引擎干擅长的事**——每题一个 Claude Code 主控进程，多 flag 题用 Task 工具并行派发 4-8 个子 agent 分治（入口/横向/提权/CVE/云逃逸/凭证攻击等方向），独立上下文共享运行时；
2. **自研调度层管全局经济**——3 槽位并发、难度分级预算、有断点给满/无断点降级快验、零进展退出+末尾回挖、最后 45 分钟 endgame 只打快赢题；
3. **纪律层保每一分质量**——CLAIM/EVIDENCE 证据提交、全通道错提熔断、hint 买方向经济学（买一次终身复用）、advisor+critic 双角色指挥重试。

## 技术架构

```
┌─────────────────────────── 调度层 scheduler ───────────────────────────┐
│ 3 并发槽位 · 预算分级（有断点满额/无断点快验）· 零进展退出+末尾回挖      │
│ endgame 收尾（剩45min只放快赢题）· 409 轮转 · 容器轮换元数据注入         │
├─────────────────────────── 执行层 worker/harness ──────────────────────┤
│ 每题主控 Claude Code + Task 子 agent 分治（8/6/4 方向按 flag 数分级）    │
│ RELAY 接力块（原语/死路/下一步即时落盘）· HOSTS 资产台账跨线共享         │
│ flag 三通道提交闭环 · 完成早停止损 · 快速断点重跑                        │
├─────────────────────────── 纪律与策略层 ────────────────────────────────┤
│ CLAIM/EVIDENCE 证据提交 · 错提熔断（auto通道≥10次关闭）· hint 置顶复用   │
│ advisor 指挥官 brief + critic 对抗审查 · effort 分级（medium/hard 满思考）│
├─────────────────────────── 基础设施（Docker 镜像）──────────────────────┤
│ fscan/chisel/flag_sweep/creds_replay 横向四件套 · nuclei CVE 预侦察      │
│ PayloadsAllTheThings · flash/pro 双模型分层 · 启动三重自检               │
└─────────────────────────────────────────────────────────────────────────┘
```
