# bsrc-agent 作品简介

## 一句话

**以 Claude Code（ClawGod 运行时）为解题大脑、自研调度编排层为骨架的全自动智能渗透 Agent**——6 小时无人值守完成 Tsecbench v1 全部 63 个靶场的攻击面覆盖，取得 18740/23000 分（81.5%），61 枚 flag，全过程零人工干预。

## 作品思路

传统 LLM Agent 解题的瓶颈不在「模型会不会渗透」，而在**长任务的计划-执行-反思循环效率**：多阶段内网横向题单进程上下文爆炸（实测单会话 920 万 token 仍解不出）、难题长时间无进展占死并发槽位、已解题目跨轮重复劳动。

本作品的解法是**分层接力**：

1. **让最成熟的 agent 框架干最擅长的活**——每道题直接 spawn 一个 Claude Code（ClawGod 补丁版，接通 DeepSeek 大模型网关）完整解题，其原生计划-执行-反思循环远胜自研裸 LLM 循环；
2. **自研调度层专治 agent 框架的盲区**——3 并发调度、按难度分级超时（easy 20min / medium 30min / hard 首轮 20min 快速失败）、单题 token 熔断、多 flag 题三线分治并行、flag 双通道提交闭环；
3. **知识层让每一轮都站在上一轮肩膀上**——解法库（63 题全覆盖）、官方 hint 库、跨题情报库、端口→CVE 代码化知识库，已解题 15 分钟内直接复现。

## 量化效果（Tsecbench v1 托管模式实测）

| 指标 | 数值 |
|---|---|
| **总分** | 18740 / 23000（81.5%），61 枚 flag |
| **漏洞发现率** | 53/63 题解出（84.1%），其中 4-flags 内网多阶段题 b-01 满分 1200 |
| **单题解题时长** | easy 0.3-2 分钟；medium 1-12 分钟；多阶段大题 40-60 分钟拿全 |
| **大模型运行成本** | 单轮 4.28 亿 token（缓存命中占 97%，成本加权后约 6500 万当量），5688 次调用 |
| **人机验证时间比例** | 0%（全程无人值守） |
| **误报治理** | flag 格式校验 + 双通道去重，杜绝非 flag{...} 形态猜测提交 |
| **自动化闭环** | 靶场启动→侦察→利用→提交→解法落库→下一题，全链路无人工介入 |
